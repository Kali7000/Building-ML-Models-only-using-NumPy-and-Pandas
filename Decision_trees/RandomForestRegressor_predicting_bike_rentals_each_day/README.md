# Random Forest Regressor (From Scratch in Pure NumPy)

A complete, end-to-end Random Forest Regressor built entirely from scratch using pure Python and NumPy. This project expands upon a custom CART Decision Tree by implementing Bootstrap Aggregating (Bagging) and Node-Level Feature Subsampling to predict daily bike sharing demand.

## Project Overview

While modern libraries like `scikit-learn` make random forests accessible via a single `.fit()` call, this project implements the underlying ensemble mathematics manually. 

By building the forest from scratch, this project demonstrates a deep understanding of how variance reduction algorithms combat the high-variance (overfitting) nature of single decision trees. The model predicts the total number of rented bikes based on complex, non-linear environmental and seasonal features.

### The Dataset
The model is trained on the [Bike Sharing Dataset](https://archive.ics.uci.edu/ml/datasets/bike+sharing+dataset) from the UCI Machine Learning Repository, utilizing features like temperature, humidity, windspeed, and day of the week.

## Model Architecture & Mathematics

This model uses a custom `RandomForestRegressor` class that manages a collection of individual CART regression trees.

### 1. Bootstrap Aggregating (Bagging)
To ensure the ensemble generates diverse trees, the model uses bootstrapping. For every tree in the forest, a new training dataset is generated by sampling the original rows *with replacement*. This creates a unique statistical distribution for each weak learner.

### 2. Node-Level Feature Subsampling
If every tree splits on the strongest feature (e.g., Temperature), the trees will be highly correlated, defeating the purpose of the ensemble. To solve this, the recursive tree builder is modified to randomly select a subset of features (typically $p/3$) at **every single node split**. This forces the algorithm to explore secondary, weaker features, creating a robust, generalized forest.

### 3. Variance Reduction (CART)
The underlying weak learners use the CART algorithm. At each node, the algorithm scans the feature subset to find the specific numerical threshold that minimizes the **Weighted Mean Squared Error (MSE)** of the left and right child nodes.

### 4. Ensemble Prediction
When new data is passed to the model, the row traverses down the binary splits of every tree in the forest. The final prediction is the mathematical mean of all individual tree outputs, effectively smoothing out outliers and structural noise.
